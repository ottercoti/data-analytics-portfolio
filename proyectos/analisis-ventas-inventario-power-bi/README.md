# Análisis de Ventas e Inventario en Power BI

## Descripción

Proyecto desarrollado en Power BI para analizar información de ventas y monitorear el estado del inventario mediante visualizaciones interactivas.

## Objetivo

Construir un dashboard que permita analizar el comportamiento de las ventas, identificar patrones relevantes y visualizar el estado actual del inventario para facilitar la interpretación de la información.

## Herramientas utilizadas

- Power BI
- Power Query
- DAX
- Excel
- Modelamiento de datos
- Visualización de datos

## Proceso desarrollado

1. Importación de los archivos de ventas e inventario.
2. Revisión y limpieza de los datos.
3. Transformación de información mediante Power Query.
4. Creación de relaciones entre las tablas.
5. Desarrollo de medidas y cálculos mediante DAX.
6. Construcción de visualizaciones y segmentadores.
7. Elaboración de dashboards para el análisis de ventas e inventario.
8. Revisión e interpretación de los resultados obtenidos.

## Principales análisis

El proyecto permite analizar aspectos como:

- Comportamiento de las ventas.
- Distribución de ventas por categorías y tiendas.
- Estado actual del inventario.
- Clasificación de productos según niveles de stock.
- Interacción entre distintos filtros y visualizaciones.
